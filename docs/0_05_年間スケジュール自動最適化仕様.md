# 0_05_年間スケジュール自動最適化仕様

更新履歴

- 2025-12-31: 初版作成。
- 2025-12-31: ボーナス月=2を最優先する最適化目標を追加。

---

## 1. 目的
「35日家計簿」におけるやりくり費期間を、35日と7日の12期で構成する。
7日の期間を「ボーナス月」と呼び、年2回（デフォルトは8期と12期）設定する。

## 2. 入力 / 出力
### 2.1 入力
- year: 対象年度（例: 2026）
- start_date: 当該年度のスケジュール開始日（例: 2026-01-01）
- week_start: 週の開始曜日（0=Mon..6=Sun）

### 2.2 出力
- periods[]:
  - period_index
  - days: 35 or 7
  - start_date
  - end_date（start + days - 1）
- bonus_periods[]: days=7 の period_index 一覧

## 3. ルール / 制約
1. 期間数は12期固定。
2. 期間長は 35 または 7。
3. 7日（ボーナス月）は年2回。
4. 合計日数は 364日（52週）で連続する。

## 4. 自動生成（デフォルト）
- 全12期を35日で生成。
- デフォルトのボーナス月は 8期・12期（1-based）。
- start_date から連続して期間境界を割り当てる。

```
periods = [35] * 12
periods[7] = 7   # 8期
periods[11] = 7  # 12期
assign_dates(periods, start_date)
```

## 5. ボーナス月の変更
- 外側パイチャートのタップでボーナス月を変更する。
- 既存のボーナス月1つを35日に戻し、選択した期を7日にする。
- 合計日数は常に364日を維持する。

```
swap_bonus(from_index, to_index):
  periods[from_index] = 35
  periods[to_index] = 7
  recompute_dates(periods, start_date)
```

## 6. テスト観点（最小）
1. periods.length == 12
2. days ∈ {35, 7} のみで構成される
3. days=7 が2つ存在する
4. 合計日数が364日である
5. start/end が連続する
6. デフォルトが 8期・12期である
7. ボーナス月変更後も合計日数・連続性が維持される
