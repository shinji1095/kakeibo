# 年間スケジュール画面の改善案

2026-10-26

## 実装状況

この文書は初期のUI提案を記録したもの。現行の画面では基本設定を「開始する曜日・やりくり費」に絞り、開始日・ボーナス月・0週／1週・6週にする月を詳細設定へ移し、初期状態では閉じる。0週では独立した期を作らない。現行の期間構成は[年間スケジュール仕様](0_05_年間スケジュール自動最適化仕様.md)を参照。

以下の画面例と操作手順は当初案であり、現在の0週の扱いと期間数には対応していない。

## 目的

開始日、やりくり費、年2回のボーナス設定（0週は暦月、1週は期）、6週にする通常期を、設定の意味と結果を見ながら決められる画面にする。

## 現在の分かりにくい点

- ボーナス月と週数が横並びの小さなプルダウンで、選択状態を一目で読みにくい。
- 6週にする期は「第1期」など番号だけで、日付や暦月との対応が見えない。
- 円グラフが大きく、0週の期間は図形として見えない。設定した結果を確認するにはさらに下へスクロールする必要がある。
- エラーが入力欄から離れた場所に出る。保存ボタンも長い一覧の後にある。

## 推奨する画面

```text
┌──────────────────────────────┐
│ 年間スケジュール       ‹ 2026年 › │
│ 1/1 開始 → 12/30 終了・52週       │
├──────────────────────────────┤
│ やりくり費  50,000円 / 期    編集 │
│ 開始日      2026年1月1日     変更 │
├──────────────────────────────┤
│ ボーナス設定（年2回）              │
│ 1回目 [0週]  1週               │
│ 暦月: 1月 2月 ... [9月] ... 12月 │
│       9/10・第2週から            │
│ 2回目  0週  [1週]              │
│ 7日間にする期: [第12期]          │
│       12/24〜12/30・第4週から   │
├──────────────────────────────┤
│ 6週にする通常期  1つ選択           │
│ ○ 第1期  1/1〜2/11  5週→6週     │
│ ○ 第2期  2/12〜3/18 5週→6週     │
├──────────────────────────────┤
│ 変更後の期間                      │
│ ① 1/1〜2/11   6週              │
│ ...                          │
│ ⑧ 9/10 境界・集計なし            │
│ ...                          │
│ 12期 / 52週・変更後の開始日       │
├──────────────────────────────┤
│        [この内容で保存]           │
└──────────────────────────────┘
```

上の具体的な日付は説明用。0週の行は日付範囲を表示せず、「9/10に境界・集計なし」と表現する。

## 操作

1. 初期表示は保存済みの要約を上段に置く。年切り替え時は対象年を大きく表示する。
2. 予算額と開始日は短い行にまとめる。開始日はタップで日付選択、予算額は金額入力シートで編集する。
3. 0週の場合は12か月のグリッドから暦月を選ぶ。1週の場合は12期の一覧から7日間にする期を選ぶ。
4. 各回の0週／1週は2択のセグメントボタンで表示する。選択直後に「何月何日・第何週から」と実際の境界を更新する。
5. 0週を選んだ時だけ、必要な数の「6週にする通常期」を表示する。候補には期番号・現在の開始日と終了日・変更後の週数を並べる。選択できない候補には理由を示す。
6. 変更後の12期は円グラフではなく日付付きの縦タイムラインを主表示にする。ボーナス期間は強調色、6週は別のアクセント、0週は線上の境界マーカーで表す。
7. 選んだ暦月や期にボーナス期間を置けない場合は、選択欄の近くに理由を出す。保存ボタンは画面下に固定し、有効なプレビューがある時だけ押せる。
8. 年を切り替える前に未保存の変更があれば、破棄するか保存するか選べるようにする。
