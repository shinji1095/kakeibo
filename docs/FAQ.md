# 年間スケジュール変更に関する確認事項

## 1. ボーナス月の「0週／1週」の意味

**質問:** 選択した暦月のやりくり費集計期間を0週または1週にし、残りの週を他の月へ再配分しますか。それとも従来の35日／7日の期間構成を維持し、集計対象だけを切り替えますか。

**理由:** 12期・年間52週という既存条件のもとで、ボーナス月を0週にすると35日×10期だけでは2週不足します。期間境界、予算残額、取引の集計範囲に影響します。

回答：ボーナス月を0週にするとどこかの月のやりくり費集計期間を6週にします。その設定も追加で必要です。ボーナス月を1週にする設定は従来の35日 / 7日の期間構成を維持

## 2. ボーナス月の選択数

**質問:** ボーナス月は従来どおり年2か月固定ですか。それとも0～12か月を任意に選べますか。

**理由:** 期間配分、設定画面、既存データの移行方法に影響します。

回答：ボーナス月は任意に選べるようにしたい。一方で、その月の何週目からボーナス月になるのかは計算が必要だと思うので、ユーザーに分かりやすいように表示や確認が必要

## 3. 家計簿の開始日

**質問:** 初回の運用開始日を一度だけ指定しますか。それとも毎年の年間スケジュール開始日（月日）を指定しますか。

**理由:** 年の切り替わりと過去・未来の期間の生成方法が変わります。

回答：毎年の年間スケジュール開始日を指定

## 変更が及ぶ箇所

- 年間スケジュールの期日・ボーナス判定とデータベース保存形式
- ホームの期間カレンダー、日割り目安、やりくり費残額
- 期間別の取引一覧、内訳、推移と年またぎの期間移動
- ボーナス残高の年間予算計算
- やりくり費設定画面と年間スケジュール画面の導線

旧実装は `35日×10期 + 7日×2期 = 364日` でした。現在は暦年と同じ365日／366日になるよう、最後の通常期に1日／2日を加えています。

## 4. 任意のボーナス月数と年間52週の両立（確認中）

**質問:** 通常期を4〜6週、年間を52週とする場合、ボーナス月が多い組み合わせは成立しません。成立する組み合わせだけ選択可能にしますか。それとも通常期を7週以上にもできるようにしますか。

**理由:** 例として5つのボーナス月をすべて1週にしても、残り7期を6週にした合計は47週です。

**追加確認:** ボーナス月が1か月だけで1週の場合、残り11期を35日にすると年間56週です。52週にするには一部の通常期を4週（28日）にする必要があります。通常期の4週も許可しますか。

回答：ボーナス月は必ず2回にします。

## 5. 暦月からボーナス期間への対応（確認中）

**質問:** 選択した暦月に入って最初の期間境界からボーナス期間を開始しますか。それとも暦月1日を開始日としますか。

**理由:** 開始日から35日単位の境界は暦月1日と一致せず、ボーナス月の何週目から始まるかが変わります。

回答（2026-10-26改訂）：0週では独立したボーナス期を作らない。ボーナス月は暦月の設定として保存する。1週は期番号で選ぶ。

## 6. 0週と1週での選択方法

回答：0週にする場合は暦月からボーナス月を選ぶ。1週にする場合は従来と同じく、存在する期の中から7日間のボーナス期にする期を選ぶ。

補足（2026-10-26改訂）：0週が2回なら、日付のある期は通常期10期になる。0週が1回なら通常期10期と1週のボーナス期1期、0週がなければ通常期10期と1週のボーナス期2期になる。1週にする期番号は、その構成で存在する期から選ぶ。

## 7. 基本設定の6週の期数（回答済み）

**質問:** 基本設定では8月と12月を0週、9・10・11月の3期をすべて6週にすると指定された。一方、0週が2回の年については「5週が8期間と6週が2期間の合計10期間」とも指定された。年間52週・10期のまま3期を6週にするなら、残る7期のうち1期を4週にする必要がある。どちらの配分を採用するか確認中。

回答：一年は365日か366日であるため52週とプラス1日か2日という表現が適切である。つまり、9, 10月はキリよく6週を実現できるが、11月も6週分の枠がなければそもそも365日の家計簿を作ることができない。家計簿は一年に一回新しく作り直す必要があるので1月になったらやりくり期間を新しく作り直す必要があるだろう。

実装上の配分（再改訂）：8月・12月を0週として独立した期を作らない。1〜7月期は各35日、9・10月期は各42日、11月期は35日＋暦年の残り1日／2日（36日／37日）とする。11月期の6週目は1日／2日だけであり、7月期などを4週にしない。合計365日／366日。各期の月名は選択用のラベルであり、実際の日付は一覧で確認できる。新規年はその年の1月1日〜7日の最初の月曜日から生成する。
